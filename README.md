This is some stuff I am using to scrape an order from a food back (the python script) and use it to create orders at a monthyly distribution event.

It is not ready for public use yet as I am still working out some issues. I plan to make it ready for public use in the future.

Steps:

1. Create a venv for the project
2. Activate the venv (. ./venv/bin/activate)
3. Create project in Google Cloud
4. Make sure the person running the script is a registered developer in Google Cloud. (https://developers.google.com/profile/u/me)
5. Make sure the person running the script has permissions in Google Cloud. (https://console.cloud.google.com/iam-admin)
6. Make sure the person running the script is authorized to run a test on the project
